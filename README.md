# Знакомства ГУУ — Telegram-бот

Бот знакомств в стиле Леонардо Дайвинчик специально для студентов ГУУ.

## Возможности
- Простая регистрация (имя → пол → возраст → институт → направление → курс → описание → фото), анкета появляется в поиске сразу; институт выбирается кнопками
- В анкетах видны институт, направление и курс
- Просмотр анкет с кнопками ❤️ / 👎
- ❤️ отправляет заявку: получатель видит анкету отправителя и кнопки «✅ Принять заявку» / «✖️ Отклонить»
- Доступ к анкете и кнопка «💬 Написать» появляются только после принятия заявки — оба получают уведомление с анкетой друг друга
- Кнопка «🚨 Пожаловаться» на любой анкете — жалоба приходит админу с анкетой и кнопками «Удалить анкету» / «Отклонить жалобу»
- Админ-панель (`/admin`)

## Быстрый запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи токен.

2. Установи зависимости:
```bash
pip install -r requirements.txt
```

3. Укажи токен одним из способов:

**Вариант А** — в файле `config.py`:
```python
BOT_TOKEN = "123456:ABC-DEF..."
```

**Вариант Б** — создай файл `.env`:
```
BOT_TOKEN=123456:ABC-DEF...
```

4. Запусти:
```bash
python bot.py
```

## Админ
Твой ID уже прописан: `1960993749`

Команды админа:
- `/admin` — статистика
- `/reports` — открытые жалобы: анкета + кнопки «🗑 Удалить анкету» / «✖️ Отклонить жалобу»

При новой жалобе тебе сразу придёт карточка с анкетой и кнопками действий.
Удалённая анкета полностью стирается из базы, а её владелец получает уведомление.
